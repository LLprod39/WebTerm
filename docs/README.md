# Project Docs

This folder keeps project documentation outside the repository root.

- `PIPELINE_NODES_SPEC.md` - Studio pipeline node reference.
- `mars/` - MARS-generated architecture, status, task, and file-list artifacts.
- `qa/` - QA and release validation plans.
- `reports/` - project audits, review plans, and frontend worklogs.
- `local/` - local-only notes and internal documents ignored by git.
