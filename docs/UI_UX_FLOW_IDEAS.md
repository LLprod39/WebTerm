# UI/UX: идеи улучшений (тема Flow и дальше)

Дата: 2026-07-18. Контекст: добавлена тема Flow (light/dark) по референсу FlowAI —
белый минимализм, чёрные CTA, зелёные статусы, топбар с крошками и поиском,
«плавающий лист» контента. Ниже — что сделает платформу заметно приятнее и
функциональнее. Отсортировано по соотношению «вау / трудозатраты».

---

## 1. Быстрые победы (день-два каждая)

### 1.1. Командная палитра (Ctrl+K / Cmd+K)
Поиск в топбаре Flow сейчас декоративный — сделать его входом в полноценную
палитру (cmdk уже в экосистеме shadcn):
- навигация: «серверы», «агенты», «настройки» — мгновенный переход;
- сущности: имя сервера → подключиться к терминалу; имя агента → карточка;
- действия: «запустить пайплайн X», «переключить тему», «сменить язык»;
- недавнее: последние 5 серверов/прогонов сверху.

Файлы: новый `frontend/src/components/CommandPalette.tsx`, данные — уже
существующие react-query кэши (`servers`, `agents`). Хоткей глобальный,
кнопка-поиск в `FlowTopbar.tsx` открывает её же.

### 1.2. Скелетоны вместо спиннеров
Списки серверов, таблицы прогонов, карточки дашборда при загрузке показывают
контурные скелетоны (shadcn `Skeleton` уже есть в ui/). Ощущение скорости
меняется радикально, особенно в светлой теме.

### 1.3. Тосты с Undo
Для деструктивных действий (удаление сервера из группы, остановка агента) —
тост «Удалено · Отменить» на 5 секунд вместо модалки подтверждения там, где
операция обратима. Меньше кликов, безопаснее по ощущению.

### 1.4. Хоткеи навигации + шпаргалка
`g d` → дашборд, `g s` → серверы, `g a` → агенты, `g c` → чат, `?` — оверлей
со шпаргалкой всех хоткеев. Дёшево, а опытные операторы влюбляются.

### 1.5. Индикатор WS-соединения
Тихая точка в топбаре (зелёная/жёлтая/красная) — статус WebSocket операторского
чата и терминалов. При обрыве — ненавязчивый баннер «переподключаюсь…».
Сейчас обрыв замечают только по молчанию чата.

## 2. Средний калибр (неделя)

### 2.1. KPI-строка дашборда как в референсе
Четыре карточки с большими цифрами (Manrope 700, табличные цифры уже в теме):
- «Серверы онлайн» N/M + дельта за сутки;
- «Прогоны агентов» за 7 дней + спарклайн;
- «Активные алерты» с красной дельтой;
- «Токены ИИ» за неделю (данные из llm-слоя).

Спарклайны — крошечные, 1.5px линия, без осей. Данные для первых двух уже
есть (collector v2, история прогонов).

### 2.2. Карточки серверов с мини-метриками
На `/servers` в карточку сервера добавить: CPU/RAM спарклайн (последний час из
рядов collector v2), кольцо здоровья (уже есть в мониторинге — переиспользовать
компонент), время последнего подключения. Клик по кольцу → страница insights
этого сервера.

### 2.3. Timeline прогона агента
Страница прогона (`AgentRunPage`) как вертикальный степпер: каждый шаг —
строка с иконкой инструмента, статус-пилюлей (зелёная/красная/серая), временем
и сворачиваемым выводом. Сейчас это стена текста; степпер сделает прогоны
читаемыми за секунды. Референс — карточки инструментов в операторском чате,
язык уже придуман.

### 2.4. Пустые состояния с действиями
Каждый пустой список (нет серверов, нет агентов, нет пайплайнов) — не «ничего
нет», а карточка с 2–3 шаблонами старта, как «Recent Using Templates» в
референсе: «Добавить SSH-сервер», «Создать агента из шаблона „бэкапы"»,
«Импортировать из группы». `workspace-empty` класс уже стилизован в Flow.

### 2.5. Центр уведомлений (колокольчик в топбаре)
Слайд-овер справа: алерты мониторинга, завершившиеся прогоны, прогнозные
события из «ленты будущего». Группировка по дням, непрочитанный счётчик-бейдж.
Бэкенд-события уже существуют (alerts, forecast watcher) — нужен только
агрегирующий endpoint + панель.

## 3. Большие фичи (вау-эффект)

### 3.1. Ассистент как слайд-овер с любой страницы ★ главная идея
Как в референсе FlowAI: операторский чат открывается панелью справа поверх
текущей страницы (не переходом на /chat). Кнопка — плавающая в углу или в
топбаре.

Киллер-часть — **контекст страницы**: панель знает, где открыта:
- на карточке сервера → чипы «проверь диски», «покажи load average», «что в
  логах за час»;
- на прогоне агента → «почему упал шаг 3?», «повтори с фиксом»;
- на insights → «объясни этот прогноз», «что сделать превентивно?».

Технически: WS-протокол операторского чата уже есть (`useOperatorChatWs`),
нужен компонент-обёртка `AssistantDrawer` + передача контекста страницы первым
системным сообщением. Это превращает чат из «страницы» в вездесущего
напарника — самый большой UX-скачок из возможных здесь.

### 3.2. Сплит-вид «терминал + ассистент»
В терминале — кнопка «спросить про вывод»: выделил кусок вывода → отправился
в панель ассистента как цитата. Обратно: ассистент предлагает команду —
кнопка «вставить в терминал» (с typed-confirm для опасных, механика уже есть).

### 3.3. Живой дашборд-«командный центр»
Объединить: KPI-строка (2.1) + кольца здоровья серверов + лента будущего +
последние прогоны — одна страница, обновляется по WS без перезагрузки.
Режим «на стену» (полноэкранный, крупные цифры) для дежурного монитора.

### 3.4. Конструктор расписаний для агентов
«Каждый будний день в 9:00», «каждые 15 минут» — человеческий cron-builder
с предпросмотром следующих 3 запусков. Убирает главный барьер к регулярным
мини-агентам.

## 4. Полировка темы Flow (по мелочи, после визуальной проверки)

- Плотные экраны (Kubernetes, Studio): проверить, что белые карточки не
  сливаются — возможно, добавить `surface-2` фон секциям.
- Терминал внутри «листа»: тёмный xterm на белом листе — проверить рамку
  (сейчас терминал остаётся тёмным намеренно).
- Логин-страница: применить Flow-язык (сейчас может выглядеть от старой темы).
- Мобильный сайдбар (Sheet): проверить фон/границы в flow-dark.
- Графики мониторинга: палитру линий подвести под токены Flow (зелёный/синий/
  янтарный из темы, а не хардкод).

## Порядок, который советую

1. **1.1 палитра** + **1.2 скелетоны** — мгновенный прирост ощущения качества.
2. **3.1 ассистент-слайд-овер** — главный вау и главная польза.
3. **2.1 KPI + 2.2 карточки серверов** — дашборд начинает выглядеть как референс.
4. **2.3 timeline прогонов** + **1.3 undo-тосты** — глубина.
5. Остальное по мере надобности.
