# Информационная архитектура

Один shell, четыре пространства плюс обзор. Навигация группирует задачи, не Python modules.

- Обзор: состояние доступной инфраструктуры и внимание оператора.
- Инфраструктура: Серверы, Мониторинг, Kubernetes. Терминал и файлы открываются из контекста конкретного сервера.
- Автоматизация: Playbooks, Pipelines, Запуски, Черновики и расписания.
- Интеллект: Agents, Chat, Skills, MCP, Memory, MARS.
- Управление: Users, Groups, Permissions, Audit, Plugins; настройки сгруппированы по задаче.

В первой области — таблица с быстрым поиском и главным действием. Объект открывается в отдельной рабочей области; короткое редактирование — в drawer. Технические details раскрываются по запросу. Пользовательские подписи на русском, команды/идентификаторы остаются в исходном виде.

Ctrl/Cmd+K открывает поиск разделов и доступных серверов. Тяжёлые рабочие области загружаются отдельно. На ноутбуке shell сворачивается, content сохраняет ширину, таблицы прокручиваются локально.
