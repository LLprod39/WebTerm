# Design System Specification (`DESIGN.md`)

## 1. Color System
- **Palette:** Use OKLch for perceptual uniformity.
- **Semantic Tokens:**
  - `bg-primary`: Background color.
  - `text-primary`: Text color.
  - `brand-accent`: Primary brand color.
- **Contrast:** Ensure WCAG AA compliance.

## 2. Typography
- **Scales:** Define modular scales (e.g., 1.25 ratio).
- **Font Stacks:** List primary and fallback fonts.
- **Weights:** Specify semantic usage (e.g., `heading-bold`, `body-regular`).

## 3. Spacing & Grid
- **Scale:** 4px or 8px base unit.
- **Layout:** Specify max-width and margins for containers.

## 4. Components
- **Buttons:** Styles for primary, secondary, ghost.
- **Inputs:** Focus states and error handling.
- **Cards:** Border-radius and shadow tokens.

## 5. Motion
- **Durations:** `fast`, `base`, `slow`.
- **Easings:** `in-out`, `bounce`.

## 6. Voice & Tone
- **Principles:** Professional, Friendly, Minimalist, etc.

## 7. Brand Identity
- **Logo Usage:** Spacing and placement.
- **Imagery:** Style of icons and illustrations.

## 8. Anti-patterns
- **Avoid:** Dark patterns, over-saturated colors, cluttered layouts.
